# دين الله — Islamic App

تطبيق ويب إسلامي شامل: المصحف بالرسم العثماني مع التفسير والتلاوات، الأحاديث،
مواقيت الصلاة، الأذكار، الفقه والفتاوى، السيرة والتاريخ، ومكتبة كتب — مع مساعد
**مِشْكاة** للأسئلة الشرعية.

يعمل التطبيق بالعربية والإنجليزية، ويُثبَّت على الهاتف كتطبيق (PWA) ويعمل دون
إنترنت بعد أول زيارة.

---

## التشغيل

```bash
npm ci        # تثبيت التبعيات كما هي مثبَّتة في package-lock.json
npm run dev   # خادم التطوير على http://localhost:3000
```

| الأمر | الغرض |
| --- | --- |
| `npm run dev` | خادم التطوير |
| `npm run build` | بناء نسخة الإنتاج في `build/` |
| `npm start` | خدمة النسخة المبنيّة |
| `npm test` | الاختبارات بوضع المراقبة |
| `npm run test:ci` | الاختبارات مرة واحدة (للـ CI) |
| `npm run lint` | فحص الكود |

يُشغَّل الفحص والاختبار والبناء آليًا على كل دفعة عبر
[`.github/workflows/ci.yml`](.github/workflows/ci.yml).

## مِشْكاة

قسم **مِشْكاة** (`/categories/mishkat`) يجيب عن الأسئلة الشرعية، ويقابل كل دليل
بمصدره: الآيات تُجلب من المصحف بالرسم العثماني وتُقارن بما ورد في الجواب، فيظهر
على كل آية وسم «مُطابق للمصحف» أو «لا يطابق نصّ المصحف».

> الوسم يعني أن موضع النصّ ثبت، **لا** أن الاستدلال به صحيح. والجواب من نموذج
> ذكاء اصطناعي وقد يخطئ في تنزيل الدليل على المسألة، فلا يُعتمد فتوى في النوازل
> الشخصية.

### المفتاح لا يوجد في هذا التطبيق

الطلبات تمرّ عبر وركر كلاودفلير الذي يحمل مفتاح النموذج، وهو الوركر نفسه الذي
يخدم [تطبيق مِشْكاة المستقل](https://hamid-tlailia.github.io/Mishkat/). لا يحمل
هذا المستودع أي مفتاح.

### ⚠️ خطوة مطلوبة عند النشر على نطاق جديد

الوركر لا يستجيب إلا للنطاقات المُدرَجة في متغيّره `ALLOWED_ORIGIN`. فإن كان
مضبوطًا على نطاق مِشْكاة وحده، ستُرفض طلبات هذا التطبيق من متصفح الزائر.

لإصلاح ذلك: **Cloudflare → Workers & Pages → الوركر → Settings → Variables**،
ثم أضف نطاق هذا التطبيق إلى `ALLOWED_ORIGIN` (بلا شَرطة في آخره)، مثل
`https://myislam-steel.vercel.app`.

عند تعذّر الاتصال تعرض الصفحة رسالة تذكر النطاق الحالي وموضع الإعداد، فلا يبقى
السبب غامضًا.

### توجيه التطبيق إلى وركر آخر

```bash
REACT_APP_MISHKAT_PROXY=https://your-worker.workers.dev npm run build
```

## بنية المشروع

```
src/
  lib/
    apiClient.js     كل الطلبات: تخزين مؤقّت، دمج المتزامن، إعادة محاولة، إلغاء
    mishkat.js       عميل مِشْكاة: البروتوكول، التدفّق، والتحقّق من الآيات
    prayerContext.js منطق بطاقة «الآن»: اقتراح الوقت والصلاة القادمة
    staticData.js    تحميل ملفات JSON الكبيرة من public/APIs عند الحاجة
  styles/
    fonts.js         الخطوط المستضافة محليًا (Cairo فورًا، والبقية عند اختيارها)
    primitives.css   المكوّنات المشتركة وأساس إمكانية الوصول
  components/        الرأس، التذييل، المشغّل، مزوّد الترجمة
  pages/             الصفحات، وكل قسم تحت pages/categories/subCategories/
  service-worker.js  التخزين دون إنترنت ورسائل Firebase
public/
  APIs/              ملفات JSON تُخدَم كنقاط API عامة وتُقرأ منها الصفحات
  library_images/    أغلفة كتب المكتبة
  PDFs/              كتب المكتبة
```

### ملاحظات

- **الخطوط مُستضافة محليًا.** يُحمَّل Cairo مباشرة، وتُجلب بقية الخطوط عند
  اختيارها من الإعدادات فقط. لا يوجد اتصال بـ Google Fonts.
- **ملفات التفسير الكبيرة** (≈ ٦ ميجابايت) تُجلب من `public/APIs/` ولا تُحزَم مع
  الكود، ويحفظها عامل الخدمة بعد أول قراءة ليعمل المصحف دون إنترنت.
- **الاتجاه** يُضبط على `<html dir>` من مزوّد الترجمة، فاستُعملت الخصائص
  المنطقية (`margin-inline-start` وأخواتها) بدل اليمين واليسار.
- **متغيّرات التصميم** كلها في `:root` داخل `src/App.css`: الألوان لكل سمة،
  وسلالم الحجم والمسافة، وارتفاعات الأسطر العربية.
- **كل طلبات JSON** تمرّ عبر `lib/apiClient.js`، فتُخزَّن مؤقتًا بعمر يناسب
  نوعها ولا تُعاد بلا داعٍ. لا تُستعمل `fetch` مباشرة إلا لرفع رمز الإشعارات
  وتنزيل ملفات الصوت.
- **بطاقة «الآن»** في الرئيسية تقترح عبادة الوقت وتعرض عدّاد الصلاة القادمة.
  لا تطلب الموقع بنفسها؛ تقرأ ما حفظته صفحة المواقيت، وإن لم يوجد اعتمدت على
  الساعة وعرضت رابطًا لتحديد الموقع.
